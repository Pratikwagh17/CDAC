Javascript:
-it is use to add functionality into webapp.
-it is loosely typed language.
-it is interpreted language.

*how to use Javascript
1.internal js:in html page we use script tag and write js code in it.
2.external js:in this we create a seperate js file and import it in html file by using script tag.

*How to display Output in Javascript
1.document.write():it display Output on webpage.it will display output in same line
2.window.alert():it will display output in model popup window.
3.console.log():it will display output in browser console or in the terminal.
4.innerHTML or DOM(Document Object Model): display output inside an element or tag.

*const
-it create constant variable,whoes value can not change during runtime
