2.Object: 
-it is an instance of class.
-object allows us to access class data-member and member-function outside class.

3.construcor:
-construcor is special memeber function of class.

4.Inheritance:
-accessing property from parent class to child class.
-to achieve this we use extends keyword between child class and parent class.

-super(): 
it represent parent class constructor in child class constructor.
-super must be first statment in child class constructor.
