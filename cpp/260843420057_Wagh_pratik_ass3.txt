QUESTION 6 – RECURSION
Topic: Recursive Function
============================================================

Problem Definition:

Write a C++ program to find the sum of all natural numbers
from 1 to N using recursion.

For example, if N = 5:

    1 + 2 + 3 + 4 + 5 = 15

Create a recursive function that accepts N and returns the
sum from 1 to N.

Do not use loops for calculating the sum.

Sample Input:

Enter N:
5

Sample Output:

Sum of natural numbers from 1 to 5 = 15


Algorithm:

1. Start.
2. Accept the value of N from the user.
3. Create a recursive function that accepts N.
4. Define the base condition when N reaches the first natural
   number.
5. Return the appropriate value for the base condition.
6. For other values, call the same function with the previous
   natural number.
7. Add the current value of N to the value returned by the
   recursive call.
8. Continue until the base condition is reached.
9. Return the final sum to main().
10. Display the calculated sum.
11. Stop.
